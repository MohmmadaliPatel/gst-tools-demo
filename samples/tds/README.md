# TDS credit check samples (synthetic)

All data here is fictional and generated by `scripts/make-tds-samples.mjs` (seeded, so it is reproducible).
Deductor TANs all start with `DEMO`; the deductee PAN `ABCDE1234F` is the standard example format.

| File | What it is |
|---|---|
| `form26as_sample.txt` | Form 26AS-style caret-delimited text, Tax Year 2026-27, 12 deductors, 43 Part I lines (statuses F/U/P), section 393 labels, two lines still on old code 194J. |
| `form26as_prev_sample.txt` | Same layout for FY 2025-26 (CRLF line endings), 8 Q4 lines with 194JB/194C. |
| `form168_sample.csv` | The same Tax Year 2026-27 lines as a flat CSV. ILLUSTRATIVE ONLY: the real Form 168 column layout is not published yet. |
| `books_generic.csv` | Books TDS receivable, 67 rows: Date, Party, TAN (filled for 6 customers), Invoice No, Gross, TDS, Section. |
| `books_tally_style.csv` | The same rows in a Tally-like voucher layout (no TAN, gross or section). Header names unverified. |
| `party_tan_map.csv` | Party to TAN pairings for customers with no TAN in books. |
| `ais_tds_sample.csv` | AIS TDS lines (illustrative headers) for the optional third-way check. |
| `expected_results.json` | Golden statuses per books row and statement line, flags and totals, written from the scenario table (not from the engine). |

Scenarios covered: exact matches, monthly aggregate lines, short reported, a whole quarter not filed, one line under a wrong PAN,
booking status U (one with deposit short) and P, a sister-entity wrong TAN, March invoices credited in April (timing, old code 194J),
a section mismatch (fee reported as commission), a 2% rate on a 10% fee, unbooked receipts and one duplicate books row.
