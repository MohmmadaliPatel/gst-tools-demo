GST e-invoice JSON builder & validator

Build IRP e-invoice JSON (schema v1.1) from a form or a CSV, or paste existing JSON to check it. Validates the GSTIN checksum, PAN, HSN/SAC, state codes, CGST/SGST vs IGST by place of supply, and the tax and rounding math, with plain-English error messages. It only builds and checks JSON and does not submit anything to the government portal.
